# CRM admin interface

CRM connection admin interface built with React, TypeScript, Vite, Tailwind CSS, and shadcn components using Base UI.

From the repository root:

```sh
npm run dev:web
npm run check
npm run build
```

The interface currently shows the Bitrix24 connection entry point. It is not wired to the API yet. Never expose the API's development `x-admin-key` in browser code.
